6 · Pass/Fail rubric (Register A)

Critical gates

  • Uses a recognized A archetype.
  • Shows one concrete product state.
  • Does not copy Linear logos, proprietary layouts, or exact UI content.
  • Does not use generic AI decoration.
  • Does not introduce a second public accent color.

Scored checks · target ≥ 16 / 20

  • Product evidence · feels like a real software state, not a diagram
  • Scale · subject occupies 60–75% of frame
  • Caption weight · intentionally composed, readable
  • Focus · one element crisp, supporting context recedes
  • Density · enough product detail to avoid generic-card syndrome
  • Fade · inactive edges and background layers dissolve into the canvas
  • Color restraint · accent under 3%, functional only
  • Depth · borders and highlights subtle, not mockup-like
  • Typography · hierarchy matches the reference scale and tone
  • Quietness · breathes without feeling empty
